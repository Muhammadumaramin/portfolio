# Blog style preference

Explicit user preference: every future article must follow the same approved style. Preserve this unless the user requests a redesign.

## Blog index

Use the current blog.html as the reference. All articles appear together in a continuous publication sequence numbered 01, 02, 03, 04, and so on. Each uses the same two-column layout: a dark-green visual panel with yellow italic text on the left, and category, headline, summary, author, publication date, reading time, and matching Read the article button on the right. Keep panel sizing, typography, spacing, separators, and buttons consistent. Stack panels and text on mobile. Do not split later articles into a separate plain-text list or interrupt the sequence with promotional notes.

## Article pages

Match the existing article template: cream background, dark-green text, yellow accents, signature MUA branding, serif headlines, readable body text, title and visual hero, author/date/reading time, central takeaway, table of contents, organized sections, source links, related articles, and author footer. Use the article's actual publication date. Preserve responsive styling and accessible link/focus behavior.

## Editorial and publishing conventions

Connect topics to Umar's e-commerce, Amazon wholesale, marketplace operations, and analytical expertise. Research factual claims; cite primary sources. Label hypothetical examples and do not invent personal results. Give each article a unique URL, title, description, canonical link, and BlogPosting metadata. Add it to blog.html in the same style and to sitemap.xml. Check links and the deployed layout. Keep the original Muhammadumaramin-github.io repository untouched.
